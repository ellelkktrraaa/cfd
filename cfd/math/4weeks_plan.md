# 四周暑假排期 · 每日待办清单（修订版）

> 目标：数学竞赛（非数学类）11月初赛 + 不荒废力学
> 每日节奏：数学 3.5-4h / 物理 1.5h / Python 可选 30min / 周日休息
> 数学题量参考：每天 10-15 道（其中 4-6 道竞赛难度），只记方法卡片和错题，不抄整题
>
> **顺序依据（见文末参考链接）**：
> - 数学按《全国大学生数学竞赛参赛指南》非数学类大纲顺序：极限 → 一元微分 → 一元积分 → **常微分方程** → … → **无穷级数**（级数在 ODE 之后！）
> - 物理按 MIT 8.01 / 郑永令《力学》顺序：运动学 → 牛顿定律 → 动量 → 功与能 → **角动量**（你现在的位置）→ 刚体 → 流体 → 振动 → 天体力学
> - 物理标注：**【高中已学·深化】** = 高中已学过，大学用微积分升级，花一半时间即可；**【大学新增】** = 全新内容，重点投入
